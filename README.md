# ShipLog Workshop

Ship a real app — **ShipLog**, an AI release-notes generator — with a *team of AI agents*,
while showcasing Docker Sandboxes (`sbx`) through the **5 Cs**: Contain · Control · Choice ·
Capacity · Coordinate.

## Two delivery versions

| Version | What it is | Status |
|---------|-----------|--------|
| **SimSpace** | Guided walkthrough — slides + recorded terminal casts. Watch & read, no typing. Zero tokens, zero cloud, never flaky. | ✅ drafted — [`simspace/walkthrough.md`](simspace/walkthrough.md) |
| **Labspace** | Live `sbx` hands-on in the browser. Real microVMs, real agents, real policy/DHI. Authoritative for exact command syntax. | ⬜ not started |
